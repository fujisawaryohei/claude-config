# mermaid で落ちやすいところ

図を書き終えたら目を通す。どれも「構文エラーで図が出ない」か「出るが読めない」になる。

## 描けない（構文エラー）

| 書き方 | 起きること | 直し方 |
|---|---|---|
| シーケンス図のメッセージに `;`（半角） | 文の区切りと読まれ、構文エラーになる（mermaid 11 で確認） | `；`（全角）か `、` にする |
| flowchart のラベルに `{}` を裸で（`A[GET /items/{id}]`） | 形の指定と読まれ、構文エラーになる（同上） | ラベル全体を `"…"` で囲む（`A["GET …/{id}"]`）。`()` `[]` `\|` も同じく囲む |
| flowchart の矢印ラベルに記号 | 同上 | `-->|"ラベル"|` と `"` で囲む |
| `participant` の別名に空白 | 別名が切れる | 別名は空白なしの英字（`S`、`RP`）、表示名は `as` の後ろに |

## 描けるが読めない

| 症状 | 原因 | 直し方 |
|---|---|---|
| flowchart が巨大に引き伸ばされる | 横幅を広げる CSS が全部の図に効いている | 広げる指定は `pre.mermaid.doc-seq` だけにし、シーケンス図の `<pre>` に `doc-seq` を付ける |
| シーケンス図が縮んで文字が読めない | 参加者が多いのに幅を広げていない | `doc-seq` を付ける（図の中で横にスクロールする） |
| 参加者の名前が重なる | 名前が長い | `<br/>` で折る（`StorylineSlide<br/>SkeletonService`） |
| box の境目が分からない | 隣り合う box が同じ色 | 色を交互にする。外部は灰色にする |
| 番号が飛んで見える | `autonumber` で、`opt` / `alt` の中にもメッセージが数えられる | 仕様どおり。キャプションで番号を引くときは描けた図で確かめる |
